# Фабрика

Термины для согласования работы и получения проверенного результата.

## Язык

**Согласованный план**:
Набор задач и условий результата, который владелец разрешил выполнить.
Изменение цели или добавление несогласованной работы требует нового согласования.

**Общий инструментарий**:
Единый управляемый набор навыков и MCP для личной работы владельца и запусков
фабрики. Представления для разных агентов происходят из одного источника.

**Граница релиза**:
Место согласованного плана, после которого изменения публикуются и проверяются
в целевом окружении. По умолчанию это конец плана; промежуточный этап отмечается явно.

**Профиль исполнителя**:
Выбранные агент и модель для выполнения определённой роли в проекте.
Профили реализации и ревью выбираются отдельно и закрепляются при запуске плана.

**Задача**:
Согласованный результат работы с условиями приёмки. Реализация, ревью, доработка
и повторные попытки относятся к одной задаче, а не создают новые задачи владельца.

**Проверенный выпуск**:
Опубликованная версия, для которой подтверждены соответствие ожидаемой версии,
доступность приложения и работа согласованного пользовательского сценария.
