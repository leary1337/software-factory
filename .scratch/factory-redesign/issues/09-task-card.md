# 09: Показывать одну понятную задачу

**What to build:** Карточка объединяет попытки и сразу показывает цель, описание, этап, результат и нужное действие.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Parent:** FACTORY-REDESIGN

**Spec stories:** 3, 9, 10, 11, 12, 14, 15, 16

- [ ] Плановые и отдельные задачи имеют единое представление; повтор и ревью не становятся отдельной несвязанной задачей.
- [ ] Цель и описание видны без раскрытия сырого промпта; краткий результат опирается на доказательства.
- [ ] При неполных данных карточка не объявляет успех и сохраняет доступ к диагностике.
- [ ] Проверены пустые, загрузочные и ошибочные состояния, 393/1440px и обе темы; для исправляемых дефектов есть падающий repro.
