# 03: Проверять чистый коммит без песочницы

**What to build:** Ревью завершается независимой машинной проверкой точного коммита в отдельной чистой копии.

**Blocked by:** 02: Запускать Codex обычным процессом на Mac.

**Status:** ready-for-agent

**Parent:** FACTORY-REDESIGN

**Spec stories:** 49, 51

- [ ] Проверка использует новый локальный запуск и отдельные исходники, HOME и зависимости.
- [ ] Незакоммиченные изменения агента не попадают в проверку; изменение проверяемых файлов обнаруживается.
- [ ] Результат и проверенный SHA доступны через API и карточку; отрицательный результат блокирует merge.
- [ ] Отмена и таймаут проверки не оставляют процессов и не создают ложный PASS.
