# 07: Удалить автоматические патрули

**What to build:** Фабрика не создаёт работу фоновыми патрулями, но сохраняет восстановление согласованных задач.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Parent:** FACTORY-REDESIGN

**Spec stories:** 43, 45, 53, 67

- [ ] Удалены роли, триггеры и видимые настройки автоматических патрулей.
- [ ] Загрузка старых настроек не запускает прежний патруль и объясняет прекращение поддержки.
- [ ] Восстановление ошибок окружения, provider retry и пользовательские планы не удалены вместе с патрулями.
- [ ] Тест подтверждает отсутствие незапрошенной работы и сохранение истории.
