# 24: Повторять только исправимую подготовку

**What to build:** Временная ошибка окружения автоматически получает ограниченный ремонт без повторения всей задачи.

**Blocked by:** 17: Готовить проект командой и рецептом JavaScript; 23: Ограничивать задачу и доработку по прогрессу.

**Status:** ready-for-agent

**Parent:** FACTORY-REDESIGN

**Spec stories:** 52, 53, 59

- [ ] Ошибки окружения, реализации и внешнего сервиса имеют разные причины и допустимые действия.
- [ ] Ремонт затрагивает окружение текущей задачи, сохраняет работу и входит в её бюджет.
- [ ] Повторная одинаковая неисправность исчерпывает лимит, а не запускает бесконечную переустановку.
- [ ] В карточке видны попытки, причина, выполненное восстановление и остановка при исчерпании.
