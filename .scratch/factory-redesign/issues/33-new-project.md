# 33: Создавать проект с согласованным стеком

**What to build:** Новый проект создаётся из выбранного и согласованного шаблона и проходит ту же проверку готовности.

**Blocked by:** 32: Подключать существующий репозиторий с проверкой готовности.

**Status:** ready-for-agent

**Parent:** FACTORY-REDESIGN

**Spec stories:** 18, 21, 23, 24, 25

- [ ] Перед созданием показаны стек, репозиторий и настройки; неподдержанный вариант не заменяется молча.
- [ ] Созданный проект проходит тот же цикл настройки, PR и готовности, что существующий.
- [ ] Повтор команды не создаёт второй репозиторий или проект.
- [ ] Без согласованной доставки новый проект остаётся на настройке, а не получает фиктивную готовность.
