# 36: Сохранять работу при закрытии локального интерфейса

**What to build:** Локальный клиент переподключается к той же очереди, не открывая фабрику в сеть.

**Blocked by:** 02: Запускать Codex обычным процессом на Mac; 09: Показывать одну понятную задачу.

**Status:** ready-for-agent

**Parent:** FACTORY-REDESIGN

**Spec stories:** 1, 2, 3, 6, 16

- [ ] Закрытие и открытие вкладки не отменяют работающую задачу и не создают новый запуск.
- [ ] Сохраняются локальная защита API и привязка сервера; новые сетевые публикации не включаются.
- [ ] Прерывание устройства отличается от закрытия вкладки; UI не обещает работу выключенного Mac.
- [ ] Ошибки связи и неполные данные не показываются как успешный результат.
