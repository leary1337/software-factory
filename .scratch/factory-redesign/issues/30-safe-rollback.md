# 30: Возвращать и проверять последнюю рабочую версию

**What to build:** При неудачном выпуске фабрика выполняет безопасный rollback и проверяет восстановленное приложение.

**Blocked by:** 29: Подтверждать версию и пользовательский сценарий.

**Status:** ready-for-agent

**Parent:** FACTORY-REDESIGN

**Spec stories:** 63, 64, 65

- [ ] Сохраняется последняя проверенная версия и основание совместимости с текущими данными.
- [ ] При совместимости возврат проходит те же три проверки; нулевой код команды сам по себе не означает восстановление.
- [ ] Нет предыдущей версии, требуется обратное изменение данных или совместимость неизвестна — проект останавливается с причиной.
- [ ] Провал восстановления не запускает бесконечный повтор; состояние rollback показано в UI.
