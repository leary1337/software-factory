# 28: Выпускать приложение на границах плана

**What to build:** Несколько задач сливаются по отдельности, но deploy происходит только в конце плана или на отмеченном этапе.

**Blocked by:** 20: Запускать сохранённую версию плана; 25: Сверять результат PR, merge и deploy перед повтором.

**Status:** ready-for-agent

**Parent:** FACTORY-REDESIGN

**Spec stories:** 13, 44, 60

- [ ] План без промежуточных границ выполняет один deploy после всех необходимых merge.
- [ ] Явная граница запускает ровно один соответствующий выпуск.
- [ ] Карточки различают merge и ожидание выпуска; план не успешен до проверки обязательных релизов.
- [ ] Повторы и рестарты не создают лишние публикации.
