# 37: Проверить чистую установку минимальной фабрики

**What to build:** На чистом локальном состоянии устанавливается согласованный состав фабрики с работающим набором навыков.

**Blocked by:** 04: Завершить переход вспомогательных процессов; 05: Удалить Docker-runtime и старые контейнерные входы; 06: Удалить Pi из доступного исполнения; 07: Удалить автоматические патрули; 08: Убрать внешние трекеры и отдельные расширения; 13: Доставлять одну версию общего набора навыков; 17: Готовить проект командой и рецептом JavaScript.

**Status:** ready-for-agent

**Parent:** FACTORY-REDESIGN

**Spec stories:** 1, 33, 48, 67, 68

- [ ] Установка включает нужный каталог и не требует удалённых CLI, расширений и системной песочницы.
- [ ] Обычный проект проходит подготовку, запуск и независимую проверку в отдельном тестовом состоянии.
- [ ] Актуальные инструкции дают один рабочий путь; устаревшие публичные документы имеют указатели.
- [ ] История старой установки не удаляется; тестовая установка не присваивает рабочую очередь.
