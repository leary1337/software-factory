# Общий каталог навыков

Источник — `factory/skill-pack/catalog.json`. Он выбирает навыки из закреплённых
в `factory/skill-pack/LOCK.json` источников. Один SHA-256 описывает содержимое
каталога, правила выбора, ресурсы и закреплённые версии. Форматы Codex и
Claude Code получают одну версию. Для `tdd` выбран источник Matt Pocock.

Фабрика автоматически доставляет профиль `factory` в отдельный HOME запуска.
Интерактивные навыки постановки доступны в профиле `personal`. Общая инструкция
автоматического исполнения передаётся каждому запуску Codex: агент следует
утверждённой задаче, а необходимость нового решения возвращает как блокировку.

Для личного Codex сначала посмотри изменения из корня репозитория:

```sh
bun --env-file=/dev/null scripts/factory-skills.ts --home "$HOME" --format agents
```

Добавь `--apply`, чтобы применить показанные изменения. Для Claude Code замени
`--format agents` на `--format claude`. Каталог назначения всегда указывается
явно. Без `--apply` команда ничего не записывает.

В `.agents/FACTORY-SKILLS.md` или `.claude/FACTORY-SKILLS.md` указана версия.
Соседний `factory-skills.json` хранит источники и список принадлежащих установщику
файлов. Повторное применение той же версии не меняет файлы. Совпадающие личные
файлы используются без присвоения. Изменённые личные файлы вызывают конфликт,
а устаревшие файлы удаляются только при совпадении с предыдущей квитанцией.
Авторизация, настройки CLI и история сессий в пакет не входят.

Этот шаг доставляет навыки. Общие MCP и управление обновлением инструментария
через интерфейс предусмотрены отдельными задачами 14–16 и 22 в
[очереди реализации](../.scratch/factory-redesign/README.md).
