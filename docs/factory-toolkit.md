# Общий набор инструментов

Канонические источники — `factory/skill-pack/` и `factory/toolkit/catalog.json`.
Набор публикуется локально с хешем содержимого исполняемых обёрток, каталога и
навыков. Каждый одобренный план и отдельный запуск сохраняет версию. Обновление
активного указателя не изменяет старые артефакты. Повреждённый артефакт не запускается.

## Источники и бесплатный режим

Проверено 14 ноября 2026 года:

| Инструмент | Режим | Источник |
|---|---|---|
| Exa | Анонимный MCP, только `web_search_exa` и `web_fetch_exa` | [Официальный MCP](https://exa.ai/docs/get-started/exa-mcp) |
| Context7 | Анонимный удалённый MCP, поиск библиотеки и документации | [Официальный пакет](https://github.com/upstash/context7/blob/master/packages/mcp/README.md) |
| Graphify | `graphifyy==0.9.108`, локальный код, `GRAPHIFY_BACKEND=none`, без автоматического модельного обновления | [Исходники](https://github.com/Graphify-Labs/graphify) |
| Playwright | MCP `0.0.85`, CLI `0.1.24`, локальный Chrome, отдельный профиль | [MCP](https://github.com/microsoft/playwright-mcp), [CLI](https://github.com/microsoft/playwright-cli) |

Бесплатный удалённый сервис имеет квоты и может быть недоступен. Проверка отличает
квоту от прочих ошибок. Агент может продолжить с достаточными альтернативными
доказательствами. Если обязательная информация отсутствует, задача должна получить
явную причину остановки. Каталог не подключает ключи оплаты или платный fallback.

Graphify получает только необходимые системные переменные: credentials моделей
не передаются. Версия графа включает Git HEAD, фактическое содержимое исходников
и версию пакета. Изменение кода требует переиндексации; изменение во время запроса
делает ответ недействительным. Конкурирующие процессы используют блокировку кеша.
Выводы графа необходимо проверять по исходникам.

## Доставка и обновление

Настройки показывают активную версию, доступные версии, зависимости и результаты
проверки удалённых сервисов. Применение выполняется явно. Можно повторно выбрать
прежнюю версию: операция идемпотентна, активные планы не переписываются.

Личные CLI подключаются командой enrollment из [локальной инструкции](factory-local.md).
Codex получает `.agents`, Claude — свой формат. При проверке сначала читаются все
изменяемые файлы; конфликт с личным содержимым останавливает запись. Чужие ключи
конфигурации сохраняются. При ошибке доставки восстанавливается прежнее содержимое,
активная версия изменяется последней. Авторизация Claude не изменяется.

Браузерные снимки хранятся вне Git-копии. На macOS сокеты используют короткий
служебный путь, связанный с домашним каталогом конкретного запуска. Завершение
запуска и отмена закрывают дерево процессов. Сохранённые тесты проекта остаются
обязательной проверкой; интерактивный MCP не заменяет их.

## Проверенные сценарии

- Реальный Codex с ChatGPT: успешные вызовы Exa, Context7 и Graphify, проверка
  найденной функции в исходниках, открытие страницы и нажатие кнопки через Playwright.
- Та же проверка из сохранённого неизменяемого набора.
- Отмена задачи с открытым браузером: все 13 наблюдавшихся процессов завершены.
- Тесты: сохранение предыдущего набора, возврат, повреждённый артефакт,
  редактированные личные настройки, квота внутри HTTP 200, блокировка графа,
  изменение незакоммиченного кода и timeout подпроцесса.

Общая приёмка всей фабрики и обновление рабочей установки фиксируются отдельно.
