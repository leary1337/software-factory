# Выполнение доверенных проектов без системной песочницы

14 ноября 2026 года владелец выбрал выполнение задач своих доверенных проектов
без системной песочницы. По последнему уточнению запуск остаётся на текущем Mac
под учётной записью локального запуска; размещение на VPS отложено. Решение
упрощает подготовку обычного окружения разработки; отдельная рабочая копия
при этом не является границей защиты между процессами и доступными учётной записи данными.

Сохраняются отдельные рабочие копии, независимая проверка закреплённого коммита,
отмена и таймауты. Текущий runtime ещё использует системную песочницу:
это согласованное направление, а не описание поставленной реализации.

Контекст и критерии приёмки: [план упрощения](../factory-cleanup-plan.md).
